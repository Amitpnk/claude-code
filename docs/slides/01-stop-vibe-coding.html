What is vibe coding?

 
“

"Vibe coding" is modern software development where you relies heavily on AI, specially LLMs to generate, refine, and debug code based on natural language prompts.

— Andrej Karpathy

Works fine for

  • Exploring Ideas
  • Hackathons
  • Low stakes projects

Breaks down for

  • Scalable systems
  • Critical Infrastructure

Technical debt — produced at machine speed.

4 failure modes of vibe coding

 
01
Context saturation
The AI loses track of decisions made earlier in the session. Code starts contradicting itself silently.
02
No source of truth
The spec lives in chat history. Invisible to your team. Impossible to reconstruct a week later.
03
Code you can't explain
You accepted it without understanding it. Debugging is guesswork. Code reviews are theater.
04
Token costs spiral
Reprompting, re-explaining, recovering lost context. All wasted spend that upfront planning eliminates.

Two workflows — same AI

 

Vibe coding

  1. Open Claude. No plan.
  2. Ask for a feature — vague prompt.
  3. Accept & paste the code.
  4. Something breaks — unknown why.
  5. Ask AI to fix it. Repeat × 40.
  6. Declare victory. Code you can't explain.

Structured AI coding

  1. Write a spec — define done.
  2. Update CLAUDE.md with context.
  3. Plan Mode — design before code.
  4. One scoped task at a time.
  5. Review each change before moving on.
  6. Maintainable code you understand.

The mental model that changes everything

 

Claude Code is not a magic solution machine. It is a brilliant junior developer who needs clear instructions, a well-documented project, and a defined scope for each task.

Vague instructions
→
Vague, inconsistent code — regardless of how good the AI is.
Undocumented project
→
Every session starts cold. Claude re-learns what you already know.
Clear spec + plan
→
Remarkable output. Production-quality. Code you can maintain.
